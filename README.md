# 📚 Biblioteca JDBC

Aplicación desarrollada en **Java 21** para gestionar una biblioteca mediante una base de datos **PostgreSQL**, utilizando JDBC y el patrón DAO.

## 🛠️ Tecnologías utilizadas

- Java 21
- PostgreSQL
- JDBC
- Maven
- IntelliJ IDEA
- Git y GitHub

## 🚀 Funcionalidades

El proyecto permite realizar operaciones CRUD sobre los libros de una biblioteca:

- **CREATE:** insertar nuevos libros.
- **READ:** consultar libros y buscarlos por ID.
- **UPDATE:** modificar información de los libros.
- **DELETE:** eliminar libros.

También incorpora una relación entre libros y autores mediante claves foráneas.

## 🏗️ Arquitectura

El proyecto utiliza el patrón **DAO (Data Access Object)** para separar el acceso a la base de datos de los modelos de la aplicación.

## 📚 Conceptos aplicados

- Programación orientada a objetos.
- Conexión a PostgreSQL mediante JDBC.
- Consultas SQL.
- PreparedStatement.
- ResultSet.
- Gestión de excepciones.
- Relaciones entre tablas.
- Operaciones CRUD.
